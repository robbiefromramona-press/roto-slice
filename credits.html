FFmpeg (GPL)

Roto-Slice uses ffmpeg.wasm, which is FFmpeg compiled to WebAssembly. The cores we load (@ffmpeg/core and @ffmpeg/core-mt, version 0.12.10) are built from FFmpeg 5.1.4 with --enable-gpl and include the GPL video encoders x264 and x265, so they are licensed GPL-2.0-or-later.

The full licence text is here: GNU GPL version 2.

Our modification

Roto-Slice patches the JavaScript file of the core (ffmpeg-core.js, and the multithreaded worker is shipped unchanged) to read big files faster and to write results to disk instead of memory. That patched file is served from this site and is under the same GPL. The patch is a small, readable script: scripts/copy-core.mjs. The large ffmpeg-core.wasm files are not modified; the page loads them from jsDelivr's copy of the npm package and checks their hash first.
